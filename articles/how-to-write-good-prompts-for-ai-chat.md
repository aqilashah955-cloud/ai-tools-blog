# How to Write Good Prompts for AI Chat Tools

If an AI chat tool gives you a vague or useless answer, the problem is usually the prompt, not the tool. A prompt is an instruction. The clearer the instruction, the better the result. This guide covers five habits that make a real difference, with examples you can try today.

## 1. Say exactly what you want

Vague prompt: "Write something about healthy food."

Better prompt: "Write a 150-word introduction for a blog post about cheap, healthy breakfasts for students. Friendly tone, simple English."

The second prompt answers four questions the first one leaves open: how long, about what exactly, for whom, and in what tone. Every detail you add removes a guess the AI would otherwise have to make.

**Try it:** take a prompt you used recently and add a length, an audience, and a tone. Compare the two answers.

## 2. Give context

An AI tool does not know your situation unless you tell it. Add the facts that change the answer.

Vague prompt: "Help me write an email to my teacher."

Better prompt: "Help me write a polite email to my English teacher. I missed yesterday's class because I was sick, and I want to ask what homework I missed. Keep it under 80 words."

Context turns a generic template into a message you can actually send.

## 3. Show an example

If you want a particular style or structure, show it. Paste one example and ask for something in the same style.

Example prompt: "Here is the style I want: [paste your example]. Now write a product description for a handmade wool shawl in the same style, about 60 words."

Examples are the fastest way to teach the tool what "good" looks like to you.

## 4. Ask for a format

Tell the tool how to shape the answer: a list, a table, steps, or short paragraphs. Formats make answers easier to use.

Example prompt: "Explain how to start a small vegetable garden. Give me 5 steps, one sentence each, for a complete beginner."

Without a format, you get a wall of text. With one, you get something you can follow.

## 5. Improve in steps

You do not need a perfect prompt on the first try. Treat the first answer as a draft, then ask for changes.

- "Make it shorter."
- "Use simpler words."
- "Add one example for a student on a small budget."
- "Rewrite the second paragraph only."

Each follow-up is a small correction. Two or three rounds usually get you from a rough answer to a finished one.

## A simple prompt formula

When you are stuck, use this shape:

**Role + task + context + format.**

- Role: "Act as an English teacher."
- Task: "Explain the difference between 'affect' and 'effect'."
- Context: "I am a beginner and I keep mixing them up."
- Format: "Give two short examples for each word."

Put together: "Act as an English teacher. Explain the difference between 'affect' and 'effect'. I am a beginner and I keep mixing them up. Give two short examples for each word."

You do not need the role every time — it is optional. Task, context, and format do the heavy work.

## What not to do

- Do not paste private information into a prompt: passwords, phone numbers, addresses, or other people's personal details.
- Do not ask the tool to write something and publish it without reading it. Check facts, names, and numbers yourself — AI tools can state wrong things confidently.
- Do not expect one prompt to do everything. Break big jobs into small prompts: outline first, then one section at a time.

## Practice this week

Pick one real task — an email, a study note, a social media caption — and write the prompt using the formula above. Then improve the answer with two follow-ups. That is the whole skill: clear instruction, then small corrections.
